# AGENT LOG

I not only used AI tools to build this but also added an AI tool in this project to increase the feature-set and application of it.

-   Firstly I used AI help in order to plan out the project. What sort of features can we implement and what technologies we might use. ChatGPT was really helpful for this. It game me many good options but I ended up going with NextJS because of previous familiarity and its great for SEO as well.

-   Then I used AI for project management. With my previous knowledge of programming I used AI to divide the development into multiple smaller tasks that will act as their own small components and easy to digest when developing or debugging. Example - Auth system, Content Editing System, Live Preview and AI Features.

-   After this I started developing the project. I built the logic and the API, setup the database and all. But when developing the UI and all the repetitive tasks I used Copilot agentic mode which eased out all that.

-   I also integrated an AI feature in the application itself. Where the user will be able to write the content using the help of AI (Google Gemini API). They will write some sort of starting pointers and the AI will give them a more refined version of what they wrote.

-   I also took AI's help in debugging some minor issues where there was some sort of bugs in content display etc.

So overall AI was really helpful in building this project and it would have taken me quite more time if I had to do everything manually.
